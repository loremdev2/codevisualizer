Large structures render a window around the active pointer (priority: pointer → changed → neighbors → ends), with “Show focused region” / “Show more” affordances — no full render of 10k cells.

Collapse is per-structure (⌄ on the row) and whole-panel (⌃ in the header) — a big Map collapses to “15 entries” without leaving the Call Stack pushed away.

Stack/Queue get distinct colors (violet / sky) and LIFO/FIFO layouts. Queue shows FRONT/REAR; stack marks TOP and the pushed item. Already captured (as stack/queue) — but the source variable name is dropped today, so the row would say stack even if the code calls it path. A backward-compatible stackName/queueName/setName extension fixes the naming.

Proposed renderer architecture

Trace Engine → VisualStep
data only · no JSX → VariableRow
detectType(value) → dispatch → StructureRenderer
PrimitiveRenderer ArrayRenderer MapRenderer SetRenderer StackRenderer QueueRenderer MatrixRenderer LinkedListRenderer TreeRenderer GraphRenderer HeapRenderer
Detection is shape-based, never name-based (spec §20): an object of primitives → Map; array of primitives → Array; 2D array → Matrix; adjacency object → Graph; object chain with next → Linked List; val+left/right → Tree. Diffing (added/updated/removed entries, pushed/popped items) is pure functions over step vs previousStep — the tracer stays JSX-free (§22). New renderers are one file each in src/components/workspace/renderers/.
Trace model changes (all backward-compatible, optional fields): set + setName (JS Set captured by identity, not name-heuristic), stackName / queueName / visitedName, linkedList, tree, heap (+ array view), and per-step mapChanges: {added, updated, removed}[] computed in the existing normalize pass.

What I'd build first

Phase 1 (all data already in the trace, no model change): MapRenderer + MatrixRenderer + ArrayRenderer (cells + pointer arrows) + Set→chips for the existing queue/stack/visited rows. This immediately replaces the JSON blobs for every current template.

Phase 2 (small backward-compatible capture additions): set/setName + stackName/queueName/visitedName + entry-level map diffing → Map add/update/delete highlights, Set inserted/found states.

Phase 3 (new shape detectors): Linked List, Tree, Heap renderers + capture — unlocks reverse-linked-list, invert-tree, and heap templates in both JS and Python.
