What changed vs the current page

Topic grouping — algorithms are now rendered as colored sections per topic (icon + name + count), and the chip row above filters to one topic (or "All"). No more flat dump.

Stats strip — total saved, topic count, and "last saved" at a glance.

Language badges — each card shows JS/Python (stored at save time — the DB column already exists but was never written; the save flow now persists it, with detection fallback for old rows).

Relative dates — "2h ago" instead of raw dates.

Per-topic accent — each topic gets a stable icon + color (Arrays blue, Hashing orange, Trees lime…) with a deterministic fallback color for custom topics.

Sort — Recently updated / Title A–Z.

Search + topic filter still work together; empty and no-match states kept.
