# Brag Plan: DSA Lab — Vertical cut (9:16)

## What is this app?
DSA Lab is a code visualizer: paste an algorithm, run it in a sandboxed trace runner, and step
through every comparison, swap, and recursive call rendered as live visuals.

## The angle
The same demo, re-staged for a thumb: vertical phones the frame into a stack — hook words,
then the bar visualizer front and center with pointers and swaps at 100% attention. Copy is
shorter, type is bigger relative to the frame, and the story compresses to: you read code →
watch a swap happen → it's free in your browser. Centerpiece is the bar visualizer full-width
in portrait, exactly what a viewer of a coding Short wants to see.

## Hook (first 2-3 seconds)
Full-screen stacked words, huge: "You read code." (0.4s) → "You've never SEEN it." with "SEEN"
in cyan at 1.6s. Hold, then wipe down into the product.

## Key moments (the middle)
- **Reveal card** — DSA Lab wordmark + "Visualize algorithms step by step" verbatim, portrait
  card, arrives at the 3.02s beat.
- **The trace, portrait** — 6 bars `[8, 3, 5, 1, 9, 2]` full-width, `i` cyan / `j` orange
  pointer arrows, comparison bracket, swap at 10.02 with orange flash and counter tick, second
  swap at 11.02, timeline fill advancing.
- **Structure chips (2 rows)** — Arrays, Windows, Maps, Graphs, Stacks — pop in as a 2+3 grid
  on consecutive beats 13.51–15.52, all hold.

## Outro / punchline
"Now watch it think." → DSA Lab wordmark + "Open visualizer →" chip on the 20.02s strong cue.
Finger-tap affordance pulse on the CTA (mobile-native). Music fades.

## User flow worth showing
Compressed for vertical: run trace → bars swap → step through states. Code-typing scene is
dropped; the code panel appears only as a slim strip above the bars to keep bars the hero.
